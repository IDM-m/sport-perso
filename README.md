# Sport

Application web de suivi sportif : programme de la semaine, saisie des séances (muscu, cardio, circuits), pesées, bilan calorique du jour et progression de force.

**[Essayer la démo](https://idm-m.github.io/sport-perso/?demo)** : 10 semaines de données fictives, directement dans le navigateur, sans compte.

- HTML, CSS et JavaScript sans framework, installable comme application (PWA)
- Données dans Supabase (Postgres, règles RLS par compte), synchronisation Apple Santé via un raccourci iOS
- Graphiques avec Chart.js
